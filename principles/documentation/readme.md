# Documentation Principles

How to write and organize documentation, split by what each note governs:

- `voice/` — tone and naming: word choice, sentence style, titles.
- `structure/` — how notes are scoped, split, merged, and placed: single-idea boundaries, topic coverage, change-driver boundaries, knowledge vs. report, folder-level orientation.
- `linking/` — how notes reference each other, in-repo and cross-repo.
- `llm/` — writing for LLM consumption specifically: density, discoverability.
- `actual-patterns-not-aspirational.md` — cuts across all four, stays flat.
